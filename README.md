# Chat Cliente-Servidor con Sockets en Python

## Descripción

Este proyecto implementa un sistema cliente-servidor utilizando sockets en Python.

El servidor escucha en localhost:5000, recibe mensajes de clientes, los almacena en una base de datos SQLite y responde con una confirmación.

El cliente permite enviar múltiples mensajes hasta ingresar "éxito".

## Tecnologías utilizadas

* Python
* Sockets
* SQLite

## Estructura

* servidor.py
* cliente.py
* database.py

## Ejecución

1. Ejecutar el servidor:
   python servidor.py

2. Ejecutar el cliente:
   python cliente.py
